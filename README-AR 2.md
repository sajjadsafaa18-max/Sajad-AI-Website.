# Sajad AI — موقع توليد الفيديو من النص

## محتويات الموقع
- `index.html`: واجهة عربية متجاوبة تعمل على الآيفون والكمبيوتر.
- `netlify/functions/generate.js`: دالة خادم تتصل بمحرك توليد فيديو فعلي.
- `netlify.toml`: إعدادات النشر.
- `package.json`: اعتماد عميل fal.ai.

## نشر الموقع مجاناً قدر الإمكان
1. أنشئ حساباً في Netlify وارفع مجلد المشروع أو ملف ZIP إلى Netlify.
2. أنشئ حساباً في fal.ai وافتح صفحة مفاتيح API: https://fal.ai/dashboard/keys
3. أنشئ مفتاحاً سرياً.
4. في Netlify افتح: Site configuration / Environment variables.
5. أضف متغيراً اسمه `FAL_KEY` واجعل قيمته المفتاح السري. لا تضع المفتاح داخل `index.html` أو أي ملف يراه الزائر.
6. أعد نشر الموقع (Redeploy) حتى تُثبَّت الحزم وتُفعَّل الدالة.
7. افتح رابط Netlify من الآيفون وجرّب وصفاً قصيراً.

## محرك الفيديو والتكلفة
يستخدم المشروع endpoint التالي:
`fal-ai/wan/v2.2-5b/text-to-video`

وثائق المحرك:
https://fal.ai/models/fal-ai/wan/v2.2-5b/text-to-video/api

وجود حساب أو مفتاح لا يعني أن التوليد مجاني أو غير محدود. افحص صفحة الأسعار والرصيد في fal.ai قبل التجربة. كل طلب قد يستهلك رصيداً حسب أسعار الخدمة الحالية.

## الصوت العربي
زر «استمع للنص بالعربي» يستخدم Speech Synthesis المدمج في المتصفح/الجهاز. هذا صوت معاينة منفصل ولا يتم دمجه في ملف MP4 الناتج. لإضافة تعليق عربي داخل الفيديو فعلياً، يلزم ربط مزوّد TTS يدعم العربية ثم دمج ملف الصوت مع الفيديو في خدمة خادم إضافية (مثلاً FFmpeg على خادم يدعمه). لا يطلب هذا المشروع مفتاح صوت إضافياً ولا يدّعي دمج الصوت تلقائياً.

## ملاحظات مهمة
- لا يمكن تشغيل توليد الفيديو فعلياً قبل ضبط `FAL_KEY` في Netlify.
- لا تشارك المفتاح السري مع أي شخص.
- النسخة الحالية تولّد مقطعاً قصيراً؛ مدة الفيديو وإمكاناته تعتمد على النموذج المتاح.
- رابط الفيديو الذي يرجعه المحرك مستضاف لدى المزوّد وقد لا يكون تخزيناً دائماً.
